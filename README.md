# AQUA Platform Challenge - Self Pruning Network

`pip install numpy matplotlib`

1. **Tests / Gradient Check:** `python -m unittest discover tests` (Tests are included in project logic)

3. Generate Pareto Benchmark (Part 4): `python -m benchmarks.pareto_sweep`
